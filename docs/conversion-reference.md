# Conversion Reference

Temperature conversions should use Celsius, Fahrenheit, and Kelvin formulas with consistent decimal handling.

- Celsius → Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit → Celsius: `(F − 32) × 5/9`
- Celsius → Kelvin: `C + 273.15`

Test zero points and negative temperatures when changing conversion logic.
